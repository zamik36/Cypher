# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/). Пока версия 0.x, несовместимые изменения поднимают вторую цифру. Версия одна на весь продукт: сервисы, клиенты и образы; `cargo run -p xtask -- versions` проверяет, что она везде совпадает.

## [0.3.0] — готовится

Переписан с нуля после аудита: протокол v3 несовместим с 0.2 — клиенты и сервер обновляются вместе, старые данные 0.2 не переносятся. История работ — в [docs/report-2026-09.md](docs/report-2026-09.md).

### Безопасность

- Сквозное шифрование по схеме Signal (X3DH, Double Ratchet) во всех клиентах, включая PWA; сервер видит только шифртекст.
- Sealed sender для офлайн-доставки; запросы к inbox — через onion-хоп, на десктопе — через Tor.
- Ссылка-приглашение несёт отпечаток ключа хозяина: подмена ключа сервером при знакомстве обнаруживается. Коды безопасности для сверки при встрече.
- Строгая проверка подписей Ed25519; ограничены параметры Argon2 импортируемого файла личности.
- Файл, изменённый после того, как его предложили, больше не отправляется: иначе nonce чанков повторялись бы.

### Добавлено

- Несколько устройств на профиль (до шести): привязка нового устройства по QR или коду, рассылка каждому устройству собеседника, синхронизация отправленного, прочитанного и контактов между своими устройствами, отвязка.
- Push-уведомления, когда приложение закрыто: Web Push в PWA, UnifiedPush на Android.
- Голосовые сообщения и видео-кружочки на всех платформах.
- Квитанции о прочтении — один раз и только для показанных сообщений.
- Сообщение «нужно обновление», если версия сервера несовместима.

### Надёжность

- Версии хранимых данных и миграции; нечитаемая запись пропускается, а не обрывает запуск.
- Нативный клиент останавливается при сбое записи, а не отправляет состояние, которого нет на диске.
- Повторы и переподключения с экспонентой и jitter.

### Сервер

- Квоты inbox, лимиты Redis, лимиты запросов и соединений, в том числе с одного адреса.
- Сертификаты перечитываются без рестарта; отдельные права каждого сервиса в NATS.
- Эндпоинт готовности `/ready` и healthcheck'и.

### Эксплуатация

- Деплой образов, собранных из конкретного коммита, с автоматическим откатом на последний здоровый.
- Сервисы без root, раздельные сети, Grafana не наружу.
- Алерты в Telegram, дашборд на реальных метриках, ежедневные бэкапы с проверенным восстановлением.
